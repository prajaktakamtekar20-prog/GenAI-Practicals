# Face Generation using DCGAN

## Project Title

Face Generation using Generative Adversarial Networks
(DCGAN) on the CelebA Dataset

## Aim

To implement a Deep Convolutional Generative Adversarial
Network using PyTorch and generate realistic synthetic
human face images.

## Technologies Used

- Python
- PyTorch
- Torchvision
- Flask
- HTML
- CSS
- JavaScript
- CelebA Dataset

## Model

The project uses a Deep Convolutional Generative
Adversarial Network (DCGAN).

The trained Generator model is stored in:

generator.pth

## How to Run

Install the required libraries:

pip install -r requirements.txt

Run the Flask application:

python app.py

Open the browser:

http://127.0.0.1:5000

Click:

Generate Face

The trained Generator will generate a new synthetic
human face from random noise.
